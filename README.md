# 30-Day Interactive Website Lab

歡迎來到前端互動實驗場

## 目前進度

- Day 1｜動畫不會 DOM？從掛載看懂 Vue 生命週期
- Day 2｜GSAP 入門（1）：認識基礎參數
- Day 3｜用Timeline管理動畫流程
- Day 04–30：施工中...

啟動後可從 `#/day-01` 或 `#/day-02` 進入各日 Demo。

## 本地端運行

```sh
npm install
npm run dev
```

正式建置：

```sh
npm run build
```

預覽建置結果：

```sh
npm run preview
```

## 技術應用

Vue 3、Vite、Vue Router、Pinia、GSAP。
